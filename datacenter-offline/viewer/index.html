Open GLPI

Click a name to rename it. Status refreshes every 30 seconds; a new or renamed device shows in it within about a minute. SSH opens your ssh:// handler (e.g. MobaXterm or PuTTY) and copies ssh <ip>; RDP downloads a .rdp file that opens Remote Desktop (mstsc).

Add devices

One device per line: IP address, then an optional name. Without a name the IP is used; you can rename it later.
