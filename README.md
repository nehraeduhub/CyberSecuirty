# CyberSecuirty – NehraEduHub

- 🌐 **Course website**: `index.html`
- 🛡️ **[CyberSec AI Agent](ai-agent/)**: a portable, offline AI cybersecurity agent with a professional web UI.
  It runs an uncensored local AI model (Ollama / LM Studio) to analyse SIEM exports and logs, correlate incidents,
  score user behaviour (UEBA), apply your trusted network inventory, audit Linux hosts and generate branded A4 PDF reports.

```bash
cd ai-agent && ./start.sh     # Windows: start.bat
```

See [ai-agent/README.md](ai-agent/README.md) for the full guide and
[ai-agent/docs/LINUX-GUIDE.md](ai-agent/docs/LINUX-GUIDE.md) for CPU-only Linux servers.
