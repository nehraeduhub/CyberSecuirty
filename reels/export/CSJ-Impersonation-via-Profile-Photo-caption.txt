DP किसी की भी हो, नंबर ठग का होता है।

❓ ठगी कैसे होती है?
1️⃣ अफसर, बॉस या रिश्तेदार की फोटो DP पर लगाकर नया नंबर
2️⃣ "मीटिंग में हूँ, कॉल नहीं कर सकता" कहकर चैट
3️⃣ अर्जेंट पैसे, गिफ्ट कार्ड या UPI माँगते हैं
4️⃣ असली व्यक्ति को पता भी नहीं होता

🚩 खतरे के संकेत:
🔴 नया नंबर, जानी-पहचानी फोटो
🔴 कॉल से बचना
🔴 गिफ्ट कार्ड / अर्जेंट पैसे

🛡️ ऐसे बचें:
✅ पुराने नंबर पर कॉल करके पुष्टि करें
✅ DP देखकर कभी पैसे न भेजें
✅ अपनी DP सिर्फ कॉन्टैक्ट्स को दिखाएँ
✅ नकली प्रोफाइल को Report करें

⚙️ अभी करें ये फोन सेटिंग:
🔧 WhatsApp › Settings › Privacy › Profile photo › Profile photo: My contacts → ON
🔧 Facebook › Profile › ... › Lock profile › Lock profile → ON
🔧 Instagram › Settings › Account privacy › Private account → ON
