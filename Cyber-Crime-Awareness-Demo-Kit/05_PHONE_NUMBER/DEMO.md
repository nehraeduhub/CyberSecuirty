# 05 · Phone Number — "What a number reveals"
**Tech Guardians · AUTHORISED DEMONSTRATION ONLY**

**Objective:** Show what public/reputation information a phone number exposes and
how it enables social engineering — without harassing any real number.

**Time Required:** 5–7 minutes
**Difficulty:** Beginner
**Internet:** Required. **Kali:** PhoneInfoga (metadata only).
**Offline fallback:** `SCREENSHOTS/`.

## What You Need
- A **fictional** number from `SAMPLE_DATA/` or **your own**.
- PhoneInfoga (format/carrier/region metadata) + legitimate reputation lookups.

## Step-by-Step
1. Use the fictional number (never a stranger's).
2. Show format parsing: country, region, line type (carrier metadata only).
3. Explain how spam/reputation databases flag numbers.
4. Discuss how scammers spoof caller ID to appear local/official.

## What Audience Sees
A number decoded into region/carrier + how "trust" from a familiar area code is
manufactured.

## Presenter Script
"A scammer doesn't need to hack your SIM. He spoofs a local number so your phone
shows a familiar code, and you pick up. The number isn't proof of who's calling."

## Security Lesson
Caller ID is **not** identity. Numbers leak via breaches, forwarded messages and
'enter your number to continue' forms.

## Prevention
- Don't post your number publicly; use it sparingly in forms.
- Treat caller ID as a hint, not proof — call back on official numbers.
- Use spam-blocking apps; report scam numbers.
- Never share OTP read out "to verify your number".

## Questions to Ask
- "Has a 'local' number ever turned out to be a scam?"
- "Where have you typed your number online this month?"

## Safety Warning
**Never** look up, call, or message a number that isn't the fictional sample or
your own. No OTP/SMS bombing — ever. PhoneInfoga here is metadata only.
