# Browser Privacy Checklist

- [ ] Browser and OS fully updated.
- [ ] Tracker/ad blocker installed (e.g. uBlock Origin).
- [ ] Minimal extensions; remove ones you don't use.
- [ ] Third-party cookies blocked.
- [ ] "Do Not Track" / anti-fingerprinting settings enabled where available.
- [ ] Separate browser/profile for banking vs casual browsing.
- [ ] Search engine that doesn't profile you (for sensitive searches).
- [ ] Understand VPN hides IP, not fingerprint.
- [ ] Tor Browser available for high-privacy needs.
- [ ] Review site permissions (camera/mic/location) monthly.
