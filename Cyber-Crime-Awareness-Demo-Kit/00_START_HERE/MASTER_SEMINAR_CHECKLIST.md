# Master Seminar Checklist

## 1 week before
- [ ] Confirm audience type (school / college / institute / govt) and size.
- [ ] Pick seminar length: `../01_SEMINAR_GUIDE/` (30 / 60 / 90 min).
- [ ] Choose demos appropriate to the audience (see each guide).
- [ ] Print the right handout from `../26_HANDOUTS/`.
- [ ] Get written approval + sign the authorisation checklist in `SAFETY_RULES.md`.

## 1 day before
- [ ] Run `./check_dependencies.sh`; install anything missing.
- [ ] Test `MASTER_DASHBOARD.html` on the actual laptop.
- [ ] Test `./start_phishing_demo.sh` loads locally.
- [ ] Pre-open any "Internet Required" demos in browser tabs.
- [ ] Copy `../28_MEDIA/` screenshots to the desktop as offline fallback.
- [ ] Charge laptop; bring charger, HDMI/VGA adapters, a backup internet hotspot.

## 30 minutes before
- [ ] Projector + audio test with the dark dashboard.
- [ ] Browser zoom at 125–150% so the back row can read.
- [ ] Phone on silent / airplane except for demos that need it.
- [ ] Dummy demo accounts logged in and ready.

## During
- [ ] Open with a story, not a tool (see `DEMO_FLOW.md`).
- [ ] State "AUTHORISED DEMONSTRATION ONLY" before technical demos.
- [ ] End every demo on protection.
- [ ] Watch time — don't overrun a single demo.

## After
- [ ] Hand out the printable rules / QR to the handout.
- [ ] Share reporting info (1930, cybercrime.gov.in).
- [ ] Collect feedback.
- [ ] Delete any demo data created on shared machines.
