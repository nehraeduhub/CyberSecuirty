# 00 · Start Here

Welcome to the **Cyber Crime Awareness Live Demo Kit** by **Tech Guardians**
(mentor: **Rj Nehra, Master in Cyber Security**).

**Theme:** *Think Like a Hacker — Protect Like a Defender.*

## The idea in one line
We never start with a tool. We start with a **story** the audience recognises
("Imagine you get this message…"), then reveal the technology behind the crime,
then show exactly how to stay safe.

## How to use this kit
1. Read `SAFETY_RULES.md` — the rules you must follow in every session.
2. Read `QUICK_START.md` — get the dashboard and first demo running.
3. Read `DEMO_FLOW.md` — the presentation method.
4. Pick a seminar length in `../01_SEMINAR_GUIDE/`.
5. Open `../MASTER_DASHBOARD.html` and run demos from there.

## What's inside (numbered folders)
- `02`–`07` — **Exposure**: how everyday data (name, email, username, phone,
  photo, location) leaks and is correlated.
- `08`–`13` — **Scams & social engineering**: phishing, QR, WhatsApp, digital
  arrest, UPI, fake APK.
- `14`–`20` — **Technical awareness**: passwords, browser privacy, URLs,
  domains, Shodan, network, forensics.
- `21` — **Indian cyber crimes**: 24 ready scam-awareness sheets.
- `22`–`23` — **Tools**: Kali tool cards + online tool directory.
- `24` — **Sample data**: fictional emails, numbers, messages, QR, docs.
- `25` — **Incident response & India reporting**.
- `26`–`28` — **Handouts, presentation, media**.

## Offline-first
Most demos work with **no internet**. Where a live online service is needed,
the demo is marked **"Internet Required"** and ships with an offline
screenshot/placeholder fallback so your seminar never depends on the network.

## Golden safety rule
> Fictional identities, dummy credentials, your own devices/accounts, public
> test data, or **explicitly authorised** systems — nothing else. Ever.
