# 14 · Password Awareness — "Weak, reused, breached"
**Tech Guardians · AUTHORISED DEMONSTRATION ONLY**

**Objective:** Show why weak and reused passwords fail, and how passphrases, a
password manager and MFA fix it.

**Time Required:** 6–8 minutes
**Difficulty:** Beginner
**Internet:** Not required (use samples). Optional: a strength meter online.

## What You Need
- `SAMPLE_PASSWORDS.txt`, `PASSWORD_SAFETY.md`.

## Step-by-Step
1. Show the four sample passwords. Ask: "Which do you use something like?"
2. Explain crack time: short/common = instant; long passphrase = effectively never.
3. Explain **reuse**: one breached site exposes every account sharing that password.
4. Demonstrate the fix: a long passphrase + unique-per-site + manager + MFA.

## What Audience Sees
Their real-world passwords (123456, India123, School@123) exposed as trivial,
then a memorable passphrase that's vastly stronger.

## Presenter Script
"'India123' feels clever — a word, numbers, capital. But it's in every attacker's
first guess-list. Meanwhile 'purple-tractor-river-42-moon' is longer, easy to
remember, and would take lifetimes to crack. Length beats complexity."

## Security Lesson
Attackers don't guess one password — they try leaked ones everywhere
(credential stuffing) and run dictionaries. Length + uniqueness + MFA wins.

## Prevention
- Use a **passphrase** (4+ random words) for anything you must memorise.
- **Unique** password per site; let a **password manager** remember them.
- Turn on **MFA/2FA** everywhere, especially email and banking.
- Change passwords exposed in breaches (see demo 03).

## Questions to Ask
- "Who reuses one password on 3+ sites?" (most hands)
- "Could you remember one strong passphrase instead?"

## Safety Warning
Never ask anyone to type a **real** password on screen or into any site. Use the
samples. Strength-meter sites: only type a *fake* example.
