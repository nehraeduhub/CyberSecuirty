# Password Safety (handout-ready)

## Make strong passwords
- **Length first:** aim for 15+ characters. A 4-word passphrase is ideal.
- **Unique per account:** never reuse, especially email + banking.
- **No personal info:** name, DOB, "India", "123", pet, vehicle number.
- **Avoid patterns:** qwerty, 12345, Month@Year.

## Remember them without pain
- Use a **password manager** (e.g. Bitwarden/KeePassXC — open source, free).
- You then memorise only ONE strong master passphrase + your device unlock.

## Add a second lock (MFA/2FA)
- Prefer an **authenticator app** or hardware key over SMS OTP.
- Turn it on for: email, bank/UPI, social, cloud storage.
- Even a stolen password is far less useful with MFA on.

## If a password is breached (demo 03)
- Change it immediately on the real site; change anywhere you reused it.
- Enable MFA; review recent account activity.

## One-line takeaway
> "Long passphrase + unique per site + a manager + MFA = you're a hard target."
