# Online Tools — URL / Phishing / File


| Tool | Official URL | Purpose |
|---|---|---|
| URLScan.io | https://urlscan.io | Safely load & inspect a URL (screenshot, requests) |
| VirusTotal | https://www.virustotal.com | Multi-engine URL/file reputation |
| URLVoid | https://www.urlvoid.com | Domain reputation/age |
| PhishTank | https://phishtank.org | Known-phishing database |
| Google Safe Browsing | https://transparencyreport.google.com/safe-browsing/search | Site safety status |

**Input:** a suspicious URL or file hash (never your real password/data).
**Expected output:** reputation, screenshot, detections, phishing status.
**Demo scenario:** Scan a sample lookalike URL without visiting it (demo 16); check APK hash (demo 13).
**Safety notes:** Scan, don't click. Don't upload private/sensitive files.

> **Internet Required.** URLs change over time — confirm each is the official site before the seminar. Use only on your OWN / fictional / authorised data.
