# Online Tools — Indian Cyber-Crime Resources (Official)


| Resource | Official URL / Number | Purpose |
|---|---|---|
| National Cyber Crime Reporting Portal | https://cybercrime.gov.in | Report cyber crimes (incl. financial fraud, women/child) |
| Cyber Crime Helpline | **1930** (call) | Report financial fraud fast (money-freeze window) |
| National Emergency | **112** | Police emergency |
| CERT-In | https://www.cert-in.org.in | India's computer emergency response team |
| Sanchar Saathi (DoT) | https://sancharsaathi.gov.in | Report/block lost phones, check SIMs in your name |
| RBI – banking awareness | https://www.rbi.org.in | Official banking/fraud awareness |
