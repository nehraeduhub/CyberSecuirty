# Online Tools — Domain / DNS / Internet Exposure


| Tool | Official URL | Purpose |
|---|---|---|
| crt.sh | https://crt.sh | Certificate Transparency (find subdomains) |
| SecurityTrails | https://securitytrails.com | Historical DNS / subdomains |
| Censys Search | https://search.censys.io | Internet-wide host/cert data |
| Shodan | https://www.shodan.io | Search for exposed internet-connected devices |
| ICANN Lookup (WHOIS) | https://lookup.icann.org | Domain registration data |

**Input:** a domain you OWN or are authorised to assess.
**Expected output:** registration data, DNS records, subdomains, exposed services.
**Demo scenario:** Map your own domain's footprint; reduce exposure (demos 17, 18).
**Safety notes:** Authorised/own domains only; passive lookups; look-don't-touch on Shodan.

> **Internet Required.** URLs change over time — confirm each is the official site before the seminar. Use only on your OWN / fictional / authorised data.
