# Fake Tech Support / Pop-up Scam
**Tech Guardians · AWARENESS ONLY**

**REAL-WORLD SCENARIO**
A scary pop-up or call claims the victim's computer is 'infected' and support must fix it remotely.

**HOW CRIMINAL APPROACHES VICTIM**
Fake warning pages, cold calls posing as Microsoft/antivirus, pushing a remote-access app.

**WHAT VICTIM SEES**
A full-screen virus warning, a toll-free number, an 'engineer' asking to install AnyDesk/TeamViewer.

**LIVE DEMONSTRATION**
Show how a harmless pop-up fakes alarm; link to `FAKE_CUSTOMER_CARE.md`.

**WHAT CRIMINAL WANTS**
Remote control to 'show problems', then fees or banking theft via screen-share.

**WHY VICTIM BELIEVES IT**
The warning looks technical and urgent; the 'engineer' sounds professional.

**RED FLAGS**
Unsolicited 'your PC is infected' calls/pop-ups, requests to install remote-access apps, pay by gift card.

**WHAT VICTIM SHOULD DO**
Close the page (Task Manager); never install remote apps for callers; run your own trusted antivirus.

**HOW TO PREVENT IT**
Real vendors don't cold-call about infections; never allow remote access to strangers; keep software updated.
