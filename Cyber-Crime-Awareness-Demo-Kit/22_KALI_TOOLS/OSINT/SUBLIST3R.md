# Sublist3r (Subdomain Discovery)
**TOOL PURPOSE:** Quickly list a domain's subdomains from public sources — to reveal forgotten
dev/staging/admin hosts an attacker would target first.

**INSTALLATION:** `pipx install sublist3r`  (or `sudo apt install sublist3r`)

**OPEN/RUN:** `sublist3r -d yourdomain.example`  (a domain you OWN/authorised)

**WHAT TO SHOW:** The list of discovered subdomains (e.g. test., vpn., mail.).

**WHAT THE AUDIENCE LEARNS:** Certificate/search data exposes subdomains; monitor CT logs and
decommission unused hosts (ties to demos 17 & 18).

**SAFETY WARNING:** Passive, own/authorised domains only. AUTHORISED DEMONSTRATION ONLY.

**DEMO DATA:** your own domain.

**TROUBLESHOOTING:** Results vary by source availability; combine with crt.sh for completeness.
