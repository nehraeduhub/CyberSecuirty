# SpiderFoot (OSINT Automation)
**TOOL PURPOSE:** A web-based OSINT platform that correlates data about a target
(domain/email/name) you are authorised to investigate.

**INSTALLATION:**
```bash
pipx install spiderfoot
```

**OPEN/RUN:**
```bash
sf.py -l 127.0.0.1:5001       # then open http://127.0.0.1:5001 in a browser
```

**WHAT TO SHOW:** A scan (passive modules) on YOUR OWN domain/email, visualised as
linked entities.

**WHAT THE AUDIENCE LEARNS:** How scattered public data is automatically
correlated — and why minimising exposure matters.

**SAFETY WARNING:** Authorised/own targets only; prefer passive modules. AUTHORISED
DEMONSTRATION ONLY.

**DEMO DATA:** your own email/domain, or pre-captured screenshots.

**TROUBLESHOOTING:** First run can be slow; limit modules; bind to localhost only.
