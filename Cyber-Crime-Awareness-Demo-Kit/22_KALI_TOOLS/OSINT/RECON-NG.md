# Recon-ng (OSINT Framework)
**TOOL PURPOSE:** A modular OSINT framework that automates collecting public data about an
authorised domain/person — to show how fast a profile is built.

**INSTALLATION:** `sudo apt install recon-ng`

**OPEN/RUN:**
```bash
recon-ng
# marketplace install/use modules, set SOURCE to YOUR domain, run passive modules
```

**WHAT TO SHOW:** Passive modules gathering hosts/contacts for YOUR OWN domain into a workspace.

**WHAT THE AUDIENCE LEARNS:** Automation turns scattered public data into a structured profile —
reduce what you expose (ties to demos 02 & 17).

**SAFETY WARNING:** Authorised/own targets, passive modules preferred. AUTHORISED DEMONSTRATION ONLY.

**DEMO DATA:** your own test domain, or pre-captured screenshots.

**TROUBLESHOOTING:** Many modules need API keys; use the few free passive ones for a live demo.
