# Maigret (Username OSINT, richer report)
**TOOL PURPOSE:** Like Sherlock but produces a detailed report (and can pull some
public profile details) for one handle.

**INSTALLATION:**
```bash
pipx install maigret
```

**OPEN/RUN:**
```bash
maigret aarav_rides_demo --html      # FICTIONAL handle; makes an HTML report
```

**WHAT TO SHOW:** The generated HTML report mapping the fictional identity.

**WHAT THE AUDIENCE LEARNS:** How quickly a single handle becomes a profile.

**SAFETY WARNING:** Fictional/own handles only. AUTHORISED DEMONSTRATION ONLY.

**DEMO DATA:** `../../04_USERNAME_OSINT/SAMPLE_IDENTITIES/handles.txt`.

**TROUBLESHOOTING:** If many sites error, that's normal; focus on the report
concept, not completeness. Use offline screenshots as fallback.
