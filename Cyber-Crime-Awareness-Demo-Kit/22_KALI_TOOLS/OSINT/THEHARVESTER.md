# theHarvester (Email/Domain OSINT)
**TOOL PURPOSE:** Gather publicly available emails/subdomains/hosts for a domain —
to show an organisation's public footprint (authorised domains only).

**INSTALLATION:**
```bash
sudo apt install theharvester
```

**OPEN/RUN:**
```bash
theHarvester -d yourdomain.example -b duckduckgo   # a domain you OWN/authorised
```

**WHAT TO SHOW:** Public emails/subdomains discovered from open sources.

**WHAT THE AUDIENCE LEARNS:** Attackers map your org from public data first;
reduce what's exposed (demo 17).

**SAFETY WARNING:** Only a domain you OWN or are authorised to assess. Passive
sources preferred. AUTHORISED DEMONSTRATION ONLY.

**DEMO DATA:** your own test domain, or present with pre-captured screenshots.

**TROUBLESHOOTING:** Some sources need API keys/are rate-limited; stick to free
sources (e.g. duckduckgo/bing) for a live demo.
