# Sherlock (Username OSINT)
**TOOL PURPOSE:** Find where a username exists across many sites, showing how
reused handles link your accounts.

**INSTALLATION:**
```bash
pipx install sherlock-project        # recommended
# or: sudo apt install sherlock
```

**OPEN/RUN:**
```bash
sherlock aarav_rides_demo            # a FICTIONAL handle from this kit
```

**WHAT TO SHOW:** The list of platforms where the fictional handle is "found" —
one identity scattered everywhere.

**WHAT THE AUDIENCE LEARNS:** Reusing one username lets anyone correlate your
profiles. Use different handles for sensitive vs casual accounts.

**SAFETY WARNING:** Run only on a FICTIONAL handle or your OWN. Never enumerate a
real person's accounts. AUTHORISED DEMONSTRATION ONLY.

**DEMO DATA:** `../../04_USERNAME_OSINT/SAMPLE_IDENTITIES/handles.txt`.

**TROUBLESHOOTING:** Slow/rate-limited? run on fewer sites; network timeouts are
normal — use the offline screenshot fallback if the venue Wi-Fi is poor.
