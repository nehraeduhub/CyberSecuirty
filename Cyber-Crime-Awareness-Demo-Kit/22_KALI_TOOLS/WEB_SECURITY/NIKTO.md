# Nikto (Web Server Awareness Scanner)
**TOOL PURPOSE:** Flag common web-server misconfigurations and outdated software — on a
practice target you host — to show why patching/config matters.

**INSTALLATION:** `sudo apt install nikto`

**OPEN/RUN:** `nikto -h http://127.0.0.1:8080`  (YOUR OWN local practice app)

**WHAT TO SHOW:** Findings like outdated server banners, missing security headers, risky defaults.

**WHAT THE AUDIENCE LEARNS:** Servers advertise weaknesses; keep software updated and headers set
(great for dev/IT audiences).

**SAFETY WARNING:** Scan ONLY servers you own / purpose-built training targets. Never scan
third-party sites — it is intrusive and can be illegal. AUTHORISED DEMONSTRATION ONLY.

**DEMO DATA:** a locally-hosted intentionally-vulnerable app.

**TROUBLESHOOTING:** Noisy output; for a demo, pre-run and highlight 2–3 findings.
