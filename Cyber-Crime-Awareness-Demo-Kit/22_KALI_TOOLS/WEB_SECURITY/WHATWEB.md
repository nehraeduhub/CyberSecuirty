# WhatWeb (Web Fingerprint)
**TOOL PURPOSE:** Identify technologies a website runs (CMS, server, frameworks)
— to show how much a site reveals about itself.

**INSTALLATION:**
```bash
sudo apt install whatweb
```

**OPEN/RUN:**
```bash
whatweb https://example.com         # a neutral example / your OWN site
```

**WHAT TO SHOW:** Detected server, CMS, versions, and plugins.

**WHAT THE AUDIENCE LEARNS:** Websites advertise their stack; outdated components
become targets. Keep software updated and reduce version disclosure.

**SAFETY WARNING:** Fingerprint only your OWN site or a neutral example. No
intrusive testing of others. AUTHORISED DEMONSTRATION ONLY.

**DEMO DATA:** your own site, or example.com for a harmless banner.

**TROUBLESHOOTING:** Behind a proxy/CDN results may be generic — that's a privacy
win; explain why.
