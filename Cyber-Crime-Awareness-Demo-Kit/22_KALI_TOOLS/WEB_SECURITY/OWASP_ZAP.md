# OWASP ZAP (Web Security Awareness)
**TOOL PURPOSE:** A friendly web-app security scanner — to DEMONSTRATE the concept
of common web flaws on an INTENTIONALLY VULNERABLE practice app.

**INSTALLATION:**
```bash
sudo apt install zaproxy
```

**OPEN/RUN:**
```bash
zaproxy &                           # GUI; use the guided "Automated Scan"
```

**WHAT TO SHOW:** A passive/spider scan against a LOCAL deliberately-vulnerable
training app (e.g. OWASP Juice Shop you host yourself), and the alert list.

**WHAT THE AUDIENCE LEARNS:** Web apps have common, preventable weaknesses;
developers should test and patch. (Great for dev/IT audiences.)

**SAFETY WARNING:** Scan ONLY apps you own or purpose-built training targets you
host. Never scan third-party sites. AUTHORISED DEMONSTRATION ONLY.

**DEMO DATA:** a locally-hosted intentionally-vulnerable app (install separately).

**TROUBLESHOOTING:** Heavy on resources; prefer passive/spider for a live demo;
pre-run and screenshot results if time is short.
