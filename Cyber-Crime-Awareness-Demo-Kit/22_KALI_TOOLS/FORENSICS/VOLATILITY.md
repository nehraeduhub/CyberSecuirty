# Volatility (Memory Forensics — concepts)
**TOOL PURPOSE:** Analyse a memory dump to reveal running processes/connections —
shown as a CONCEPT on a sample dump.

**INSTALLATION:**
```bash
pipx install volatility3
```

**OPEN/RUN:**
```bash
vol -f sample.mem windows.pslist    # on a SAMPLE memory image
```

**WHAT TO SHOW:** Process list from a sample dump — "what was running at capture".

**WHAT THE AUDIENCE LEARNS:** Even RAM holds evidence; sophisticated investigation
can reconstruct activity.

**SAFETY WARNING:** Use only sample dumps or your own authorised captures.
AUTHORISED DEMONSTRATION ONLY.

**DEMO DATA:** a licensed teaching memory sample (download separately).

**TROUBLESHOOTING:** Needs the right OS symbol profile; for a general audience,
keep this conceptual with a screenshot rather than live.
