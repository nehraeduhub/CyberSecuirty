# Binwalk (File / Firmware Carving)
**TOOL PURPOSE:** Reveal hidden files or embedded data inside a binary/firmware/image — a
forensics concept showing files are not always what they seem.

**INSTALLATION:** `sudo apt install binwalk`

**OPEN/RUN:** `binwalk sample.bin`  then `binwalk -e sample.bin`  (a SAMPLE you own)

**WHAT TO SHOW:** Detected embedded file signatures inside one file; optional extraction.

**WHAT THE AUDIENCE LEARNS:** One file can contain many; investigators (and attackers) unpack
them — handle unknown files carefully (ties to demos 13 & 20).

**SAFETY WARNING:** Analyse only sample files you own/are authorised to inspect. AUTHORISED
DEMONSTRATION ONLY.

**DEMO DATA:** a harmless sample binary/firmware image you are permitted to use.

**TROUBLESHOOTING:** `-e` extraction may need extra utilities; the signature scan alone makes the point.
