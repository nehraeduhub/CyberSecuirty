# Autopsy (Disk Forensics)
**TOOL PURPOSE:** Browse a disk image, build timelines, and keyword-search —
to show how investigators work after an incident (on SAMPLE images).

**INSTALLATION:**
```bash
sudo apt install autopsy            # large; or use the official installer
```

**OPEN/RUN:**
```bash
autopsy &                           # opens a local web UI
```

**WHAT TO SHOW:** Opening a SAMPLE disk image, file timeline, and a keyword hit.

**WHAT THE AUDIENCE LEARNS:** Incidents leave recoverable traces; evidence must be
preserved and worked on as copies.

**SAFETY WARNING:** Use only sample images or media you own/are authorised to
examine. Preserve originals. AUTHORISED DEMONSTRATION ONLY.

**DEMO DATA:** a small practice disk image (download a licensed teaching sample).

**TROUBLESHOOTING:** First-time setup is slow; pre-ingest the image before the
seminar; have screenshots ready.
