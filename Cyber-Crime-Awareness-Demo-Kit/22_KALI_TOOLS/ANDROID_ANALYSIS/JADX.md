# JADX (APK Decompiler)
**TOOL PURPOSE:** Decompile an APK to readable code — to see what an app actually
does (read-only).

**INSTALLATION:**
```bash
sudo apt install jadx
```

**OPEN/RUN:**
```bash
jadx-gui app.apk                    # or: jadx -d out app.apk
```

**WHAT TO SHOW:** (On an authorised/benign sample) code that reads SMS or uses
Accessibility — the mechanics of OTP theft.

**WHAT THE AUDIENCE LEARNS:** An app's true behaviour is inspectable; permissions
+ code reveal intent (demo 13).

**SAFETY WARNING:** Analyse only authorised/benign samples. Never run unknown
APKs on real devices. AUTHORISED DEMONSTRATION ONLY.

**DEMO DATA:** a benign open-source APK you are permitted to inspect.

**TROUBLESHOOTING:** Large APKs are slow to decompile; pre-open before the demo.
