# MobSF (Mobile Security Framework)
**TOOL PURPOSE:** Automated static analysis of an APK — permissions, trackers,
hardcoded URLs, risk score — in a friendly web UI.

**INSTALLATION:**
```bash
# Docker is easiest:
docker run -it --rm -p 8000:8000 opensecurity/mobile-security-framework-mobsf
# then open http://127.0.0.1:8000
```

**OPEN/RUN:** Open the web UI and upload an authorised/benign APK.

**WHAT TO SHOW:** The permission list, trackers, embedded URLs and risk summary.

**WHAT THE AUDIENCE LEARNS:** A quick, visual way to judge an app's safety before
trusting it (demo 13).

**SAFETY WARNING:** Analyse only authorised/benign samples; run locally. AUTHORISED
DEMONSTRATION ONLY.

**DEMO DATA:** a benign APK you may inspect.

**TROUBLESHOOTING:** No Docker? follow MobSF's native install docs. Pre-scan and
screenshot for a smooth live demo.
