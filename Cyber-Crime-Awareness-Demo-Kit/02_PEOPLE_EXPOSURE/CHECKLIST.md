# People-Exposure Self-Audit Checklist
Tick what is currently PUBLIC about you, then reduce it.

- [ ] Full name + photo linkable to a username
- [ ] Employer / school / college named publicly
- [ ] City / neighbourhood visible
- [ ] Location tags / check-ins enabled
- [ ] Family members' names visible
- [ ] Pet names, birthdays, car number in posts
- [ ] Phone/email in a public bio
- [ ] Same username reused across platforms

**For each ticked box:** make it private, remove it, or compartmentalise.
Fewer public dots = fewer lines an attacker can connect.
