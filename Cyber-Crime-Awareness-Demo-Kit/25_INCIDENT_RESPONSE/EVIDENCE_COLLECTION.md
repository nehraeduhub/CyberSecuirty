# Evidence Collection Checklist
**Tech Guardians · AWARENESS ONLY**

Preserve everything; don't edit or delete.

- [ ] Screenshots of all messages/emails (show sender + date/time).
- [ ] Caller numbers, call timestamps, call logs.
- [ ] Transaction IDs / UTR numbers, amounts, dates, beneficiary details.
- [ ] Bank SMS/email alerts.
- [ ] Any app/APK installed (name, source link) — don't run it again.
- [ ] URLs/links received (copy text; don't click).
- [ ] Email headers for phishing mail (full/original headers).
- [ ] A written timeline of what happened, in order.

Store copies in two places. Share with 1930 / cybercrime.gov.in / your bank.
