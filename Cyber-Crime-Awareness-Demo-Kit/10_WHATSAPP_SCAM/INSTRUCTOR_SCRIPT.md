# Instructor Script — WhatsApp Scam

**Hook:** "How many of you would send a 6-digit code to a friend who asked nicely?"

**Beat 1 — the key.** Explain: when you (re)install WhatsApp, it sends a 6-digit
code to confirm the number owns the account. Whoever has that code can register
your account on their phone. So the code is literally the key to your account.

**Beat 2 — the trick.** Show mock message #1 and #2. Both aim at one thing: get
you to forward that code. "Security team", "wrong number", "help a friend" —
different masks, same ask.

**Beat 3 — the fallout.** Show mock #3. Now the attacker is inside, messaging
your parents and friends for money, as you, refusing calls.

**Beat 4 — the shield.**
1. Never share the code. WhatsApp will never ask you to forward it.
2. Turn on two-step verification (Settings → Account → Two-step verification).
3. Review Linked Devices; log out unknown ones.
4. Tell your family: "If I ever ask for money by text, call me first."

**Close:** "One 6-digit code stands between a scammer and your entire contact
list. Guard it like your ATM PIN."

> Keep everything to mock screens. Never demonstrate on a real account.
