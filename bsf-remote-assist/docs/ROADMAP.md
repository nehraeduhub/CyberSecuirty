# Build roadmap

## Phase 1 - Control plane
- Admin-controlled users
- AD/LDAP authentication
- RBAC
- Devices
- Session codes
- Audit logs
- Dashboard

## Phase 2 - Remote engine
- Windows service agent
- Screen capture/control
- WebRTC/WebSocket/relay integration
- Attended sessions
- Unattended sessions
- Reconnect after reboot

## Phase 3 - Enterprise operations
- GPO/MSI deployment
- Groups and site/unit hierarchy
- File transfer with approval
- Chat
- Multi-monitor
- Session recording
- Agent auto-update

## Phase 4 - Security and governance
- MFA
- Device certificates
- approval workflow for unattended sessions
- IP/network restrictions
- immutable audit export
- SIEM integration
- backup/DR
- vulnerability scanning and signed-agent release process
